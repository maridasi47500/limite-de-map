# limite-de-map
hey
🧱 *Limite de Map* — Le bord du connu

C’est là où la ville s’arrête… ou commence à rêver.(ou commence à voyager). dans les limites de ta ville, tu ne reveles pas ce que tu as fait à l'extérieur de ta ville, ou à un autre moment.


🎮 Fonction narrative

La *limite de map* devient :

   -

   Un *point de bascule* entre réalité et mémoire
   -

   Un *déclencheur sensoriel* : sons, odeurs, souvenirs se mélangent
   -

   Une *zone floue* : les repères se dissolvent, l’imaginaire prend le
   relais

🗂️ Intégration dans le dépôt

Crée un dossier map_limits/ avec :

   -

   villeurbanne_limit.json : coordonnées ou zones symboliques (ex. bord du
   canal, fin du tram, dernier banc du parc)
   -

   limit_sounds/ : sons déclenchés à l’approche (musique lointaine, vent,
   voix du passé)
   -

   limit_mood.md : textes introspectifs, récits de franchissement,
   souvenirs qui remontent
   -

   limit_trigger.py : script qui détecte l’approche (via GPS, heure,
   humeur, profil voyageur)
